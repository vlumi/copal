# GLC020: decision tables

The business rules of [GLC020](../programs/GLC020.md), paragraph by paragraph: each column is one path through the paragraph's decisions, with the outcome of each condition it tests, Y or N, and the actions it takes, numbered in the order they run. The WHENs of an EVALUATE are tried in order, and an IF whose THEN jumps away has the rest of its paragraph as its ELSE. The body of an inline PERFORM has a table of its own, for one pass. Under each table, each rule as a sentence, written from the conditions it tests and the statements it runs, with no more in it than the table has: a condition name with the field it is declared on and its values.

## ﾒｲﾝ-RTN

| | 1 | 2 | 3 |
| --- | :-: | :-: | :-: |
| `LK-ﾜﾚｷ-ﾍ` | Y | N | N |
| `LK-ｾｲﾚｷ-ﾍ` | | Y | N |
| → `SET LK-ﾍﾝｶﾝｽﾞﾐ TO TRUE` | 1 | 1 | 1 |
| → `PERFORM ﾜﾚｷ-ﾍﾝｶﾝ-RTN` | 2 | | |
| → `GOBACK` | 3 | 3 | 3 |
| → `PERFORM ｾｲﾚｷ-ﾍﾝｶﾝ-RTN` | | 2 | |
| → `SET LK-ﾋﾂﾞｹ-ﾌｾｲ TO TRUE` | | | 2 |

- **Rule 1.** When `LK-ﾎｳｺｳ` is `'W'` (`LK-ﾜﾚｷ-ﾍ`), it sets `LK-ｹｯｶ` to `LK-ﾍﾝｶﾝｽﾞﾐ`, performs `ﾜﾚｷ-ﾍﾝｶﾝ-RTN`, and returns to its caller.
- **Rule 2.** When `LK-ﾎｳｺｳ` is not `'W'` (not `LK-ﾜﾚｷ-ﾍ`) and `LK-ﾎｳｺｳ` is `'S'` (`LK-ｾｲﾚｷ-ﾍ`), it sets `LK-ｹｯｶ` to `LK-ﾍﾝｶﾝｽﾞﾐ`, performs `ｾｲﾚｷ-ﾍﾝｶﾝ-RTN`, and returns to its caller.
- **Rule 3.** When `LK-ﾎｳｺｳ` is not `'W'` (not `LK-ﾜﾚｷ-ﾍ`) and `LK-ﾎｳｺｳ` is not `'S'` (not `LK-ｾｲﾚｷ-ﾍ`), it sets `LK-ｹｯｶ` to `LK-ﾍﾝｶﾝｽﾞﾐ`, sets `LK-ｹｯｶ` to `LK-ﾋﾂﾞｹ-ﾌｾｲ`, and returns to its caller.

## ﾜﾚｷ-ﾍﾝｶﾝ-RTN

| | 1 | 2 |
| --- | :-: | :-: |
| `WS-ｹﾞﾝｺﾞｳ-ﾅｼ` | Y | N |
| → `MOVE LK-ｾｲﾚｷ TO WS-YYYYMMDD` | 1 | 1 |
| → `SET WS-ｹﾞﾝｺﾞｳ-ﾅｼ TO TRUE` | 2 | 2 |
| → `PERFORM VARYING ｹﾞﾝｺﾞｳ-IX FROM ｹﾞﾝｺﾞｳ-ｹﾝｽｳ BY -1 UNTIL ｹﾞﾝｺﾞｳ-IX < 1 OR WS-ｹﾞﾝｺﾞｳ-ｱﾘ` | 3 | 3 |
| → `SET LK-ﾋﾂﾞｹ-ﾌｾｲ TO TRUE` | 4 | |

- **Rule 1.** When `WS-ﾊｯｹﾝ` is `'N'` (`WS-ｹﾞﾝｺﾞｳ-ﾅｼ`), it sets `WS-YYYYMMDD` to `LK-ｾｲﾚｷ`; sets `WS-ﾊｯｹﾝ` to `WS-ｹﾞﾝｺﾞｳ-ﾅｼ`; repeats its loop varying `ｹﾞﾝｺﾞｳ-IX` from `ｹﾞﾝｺﾞｳ-ｹﾝｽｳ` by -1 until `ｹﾞﾝｺﾞｳ-IX` is less than 1 or `WS-ﾊｯｹﾝ` is `'Y'` (`WS-ｹﾞﾝｺﾞｳ-ｱﾘ`); and sets `LK-ｹｯｶ` to `LK-ﾋﾂﾞｹ-ﾌｾｲ`.
- **Rule 2.** When `WS-ﾊｯｹﾝ` is not `'N'` (not `WS-ｹﾞﾝｺﾞｳ-ﾅｼ`), it sets `WS-YYYYMMDD` to `LK-ｾｲﾚｷ`; sets `WS-ﾊｯｹﾝ` to `WS-ｹﾞﾝｺﾞｳ-ﾅｼ`; and repeats its loop varying `ｹﾞﾝｺﾞｳ-IX` from `ｹﾞﾝｺﾞｳ-ｹﾝｽｳ` by -1 until `ｹﾞﾝｺﾞｳ-IX` is less than 1 or `WS-ﾊｯｹﾝ` is `'Y'` (`WS-ｹﾞﾝｺﾞｳ-ｱﾘ`).

Source: [GLC020.cbl:70](../../../gondwana/programs/GLC020.cbl#L70).

## ﾜﾚｷ-ﾍﾝｶﾝ-RTN, in its loop

Each pass of `PERFORM VARYING ｹﾞﾝｺﾞｳ-IX FROM ｹﾞﾝｺﾞｳ-ｹﾝｽｳ BY -1 UNTIL ｹﾞﾝｺﾞｳ-IX < 1 OR WS-ｹﾞﾝｺﾞｳ-ｱﾘ`.

| | 1 | 2 |
| --- | :-: | :-: |
| `ｹﾞﾝｺﾞｳ-ｶｲｼﾋﾞ(ｹﾞﾝｺﾞｳ-IX) > WS-YYYYMMDD` | N | Y |
| → `SET WS-ｹﾞﾝｺﾞｳ-ｱﾘ TO TRUE` | 1 | |
| → `MOVE ｹﾞﾝｺﾞｳ-ｷｺﾞｳ(ｹﾞﾝｺﾞｳ-IX) TO LK-ｹﾞﾝｺﾞｳ` | 2 | |
| → `COMPUTE LK-ﾈﾝ = WS-YYYY - ｹﾞﾝｺﾞｳ-ｶｲｼ-YYYY(ｹﾞﾝｺﾞｳ-IX) + 1` | 3 | |
| → `MOVE WS-ﾋﾂﾞｹ-ﾌﾞﾝｶｲ(5:4) TO LK-MMDD` | 4 | |

- **Rule 1.** When `ｹﾞﾝｺﾞｳ-ｶｲｼﾋﾞ(ｹﾞﾝｺﾞｳ-IX)` is at most `WS-YYYYMMDD`, it sets `WS-ﾊｯｹﾝ` to `WS-ｹﾞﾝｺﾞｳ-ｱﾘ`, sets `LK-ｹﾞﾝｺﾞｳ` to `ｹﾞﾝｺﾞｳ-ｷｺﾞｳ(ｹﾞﾝｺﾞｳ-IX)`, computes `LK-ﾈﾝ` as `WS-YYYY - ｹﾞﾝｺﾞｳ-ｶｲｼ-YYYY(ｹﾞﾝｺﾞｳ-IX) + 1`, and sets `LK-MMDD` to `WS-ﾋﾂﾞｹ-ﾌﾞﾝｶｲ(5:4)`.
- **Rule 2.** When `ｹﾞﾝｺﾞｳ-ｶｲｼﾋﾞ(ｹﾞﾝｺﾞｳ-IX)` is more than `WS-YYYYMMDD`, it does nothing more.

Source: [GLC020.cbl:73](../../../gondwana/programs/GLC020.cbl#L73).

## ﾊﾝｲ-ｹﾝｻ-RTN

| | 1 | 2 | 3 | 4 | 5 | 6 | 7 |
| --- | :-: | :-: | :-: | :-: | :-: | :-: | :-: |
| `LK-ﾈﾝ = 0` | Y | N | N | N | N | N | N |
| `LK-ﾍﾝｶﾝｽﾞﾐ` | N | N | N | N | N | Y | Y |
| `WS-MM < 1 OR WS-MM > 12` | | Y | N | N | N | N | N |
| `WS-DD < 1 OR WS-DD > 31` | | | Y | N | N | N | N |
| `WS-YYYYMMDD < ｹﾞﾝｺﾞｳ-ｶｲｼﾋﾞ(ｹﾞﾝｺﾞｳ-IX)` | | | | Y | N | N | N |
| `ｹﾞﾝｺﾞｳ-IX < ｹﾞﾝｺﾞｳ-ｹﾝｽｳ` | | | | | Y | Y | N |
| `WS-YYYYMMDD < ｹﾞﾝｺﾞｳ-ｶｲｼﾋﾞ(ｹﾞﾝｺﾞｳ-IX), again` | | | | | N | Y | |
| → `COMPUTE WS-YYYY = ｹﾞﾝｺﾞｳ-ｶｲｼ-YYYY(ｹﾞﾝｺﾞｳ-IX) + LK-ﾈﾝ - 1` | 1 | 1 | 1 | 1 | 1 | 1 | 1 |
| → `MOVE LK-MMDD TO WS-ﾋﾂﾞｹ-ﾌﾞﾝｶｲ(5:4)` | 2 | 2 | 2 | 2 | 2 | 2 | 2 |
| → `SET LK-ﾋﾂﾞｹ-ﾌｾｲ TO TRUE` | 3 | 3 | 3 | 3 | 4 | | |
| → `SET ｹﾞﾝｺﾞｳ-IX UP BY 1` | | | | | 3 | 3 | |
| → `MOVE WS-YYYYMMDD TO LK-ｾｲﾚｷ` | | | | | | 4 | 3 |

- **Rule 1.** When `LK-ﾈﾝ` is 0 and `LK-ｹｯｶ` is not 0 (not `LK-ﾍﾝｶﾝｽﾞﾐ`), it computes `WS-YYYY` as `ｹﾞﾝｺﾞｳ-ｶｲｼ-YYYY(ｹﾞﾝｺﾞｳ-IX) + LK-ﾈﾝ - 1`, sets `WS-ﾋﾂﾞｹ-ﾌﾞﾝｶｲ(5:4)` to `LK-MMDD`, and sets `LK-ｹｯｶ` to `LK-ﾋﾂﾞｹ-ﾌｾｲ`.
- **Rule 2.** When `LK-ﾈﾝ` is not 0; `LK-ｹｯｶ` is not 0 (not `LK-ﾍﾝｶﾝｽﾞﾐ`); and `WS-MM` is less than 1 or `WS-MM` is more than 12, it computes `WS-YYYY` as `ｹﾞﾝｺﾞｳ-ｶｲｼ-YYYY(ｹﾞﾝｺﾞｳ-IX) + LK-ﾈﾝ - 1`, sets `WS-ﾋﾂﾞｹ-ﾌﾞﾝｶｲ(5:4)` to `LK-MMDD`, and sets `LK-ｹｯｶ` to `LK-ﾋﾂﾞｹ-ﾌｾｲ`.
- **Rule 3.** When `LK-ﾈﾝ` is not 0; `LK-ｹｯｶ` is not 0 (not `LK-ﾍﾝｶﾝｽﾞﾐ`); `WS-MM` is at least 1 and `WS-MM` is at most 12; and `WS-DD` is less than 1 or `WS-DD` is more than 31, it computes `WS-YYYY` as `ｹﾞﾝｺﾞｳ-ｶｲｼ-YYYY(ｹﾞﾝｺﾞｳ-IX) + LK-ﾈﾝ - 1`, sets `WS-ﾋﾂﾞｹ-ﾌﾞﾝｶｲ(5:4)` to `LK-MMDD`, and sets `LK-ｹｯｶ` to `LK-ﾋﾂﾞｹ-ﾌｾｲ`.
- **Rule 4.** When `LK-ﾈﾝ` is not 0; `LK-ｹｯｶ` is not 0 (not `LK-ﾍﾝｶﾝｽﾞﾐ`); `WS-MM` is at least 1 and `WS-MM` is at most 12; `WS-DD` is at least 1 and `WS-DD` is at most 31; and `WS-YYYYMMDD` is less than `ｹﾞﾝｺﾞｳ-ｶｲｼﾋﾞ(ｹﾞﾝｺﾞｳ-IX)`, it computes `WS-YYYY` as `ｹﾞﾝｺﾞｳ-ｶｲｼ-YYYY(ｹﾞﾝｺﾞｳ-IX) + LK-ﾈﾝ - 1`, sets `WS-ﾋﾂﾞｹ-ﾌﾞﾝｶｲ(5:4)` to `LK-MMDD`, and sets `LK-ｹｯｶ` to `LK-ﾋﾂﾞｹ-ﾌｾｲ`.
- **Rule 5.** When `LK-ﾈﾝ` is not 0; `LK-ｹｯｶ` is not 0 (not `LK-ﾍﾝｶﾝｽﾞﾐ`); `WS-MM` is at least 1 and `WS-MM` is at most 12; `WS-DD` is at least 1 and `WS-DD` is at most 31; `WS-YYYYMMDD` is at least `ｹﾞﾝｺﾞｳ-ｶｲｼﾋﾞ(ｹﾞﾝｺﾞｳ-IX)`; `ｹﾞﾝｺﾞｳ-IX` is less than `ｹﾞﾝｺﾞｳ-ｹﾝｽｳ`; and `WS-YYYYMMDD` is at least `ｹﾞﾝｺﾞｳ-ｶｲｼﾋﾞ(ｹﾞﾝｺﾞｳ-IX)`, tested again, it computes `WS-YYYY` as `ｹﾞﾝｺﾞｳ-ｶｲｼ-YYYY(ｹﾞﾝｺﾞｳ-IX) + LK-ﾈﾝ - 1`, sets `WS-ﾋﾂﾞｹ-ﾌﾞﾝｶｲ(5:4)` to `LK-MMDD`, steps `ｹﾞﾝｺﾞｳ-IX` up by 1, and sets `LK-ｹｯｶ` to `LK-ﾋﾂﾞｹ-ﾌｾｲ`.
- **Rule 6.** When `LK-ﾈﾝ` is not 0; `LK-ｹｯｶ` is 0 (`LK-ﾍﾝｶﾝｽﾞﾐ`); `WS-MM` is at least 1 and `WS-MM` is at most 12; `WS-DD` is at least 1 and `WS-DD` is at most 31; `WS-YYYYMMDD` is at least `ｹﾞﾝｺﾞｳ-ｶｲｼﾋﾞ(ｹﾞﾝｺﾞｳ-IX)`; `ｹﾞﾝｺﾞｳ-IX` is less than `ｹﾞﾝｺﾞｳ-ｹﾝｽｳ`; and `WS-YYYYMMDD` is less than `ｹﾞﾝｺﾞｳ-ｶｲｼﾋﾞ(ｹﾞﾝｺﾞｳ-IX)`, tested again, it computes `WS-YYYY` as `ｹﾞﾝｺﾞｳ-ｶｲｼ-YYYY(ｹﾞﾝｺﾞｳ-IX) + LK-ﾈﾝ - 1`, sets `WS-ﾋﾂﾞｹ-ﾌﾞﾝｶｲ(5:4)` to `LK-MMDD`, steps `ｹﾞﾝｺﾞｳ-IX` up by 1, and sets `LK-ｾｲﾚｷ` to `WS-YYYYMMDD`.
- **Rule 7.** When `LK-ﾈﾝ` is not 0; `LK-ｹｯｶ` is 0 (`LK-ﾍﾝｶﾝｽﾞﾐ`); `WS-MM` is at least 1 and `WS-MM` is at most 12; `WS-DD` is at least 1 and `WS-DD` is at most 31; `WS-YYYYMMDD` is at least `ｹﾞﾝｺﾞｳ-ｶｲｼﾋﾞ(ｹﾞﾝｺﾞｳ-IX)`; and `ｹﾞﾝｺﾞｳ-IX` is at least `ｹﾞﾝｺﾞｳ-ｹﾝｽｳ`, it computes `WS-YYYY` as `ｹﾞﾝｺﾞｳ-ｶｲｼ-YYYY(ｹﾞﾝｺﾞｳ-IX) + LK-ﾈﾝ - 1`, sets `WS-ﾋﾂﾞｹ-ﾌﾞﾝｶｲ(5:4)` to `LK-MMDD`, and sets `LK-ｾｲﾚｷ` to `WS-YYYYMMDD`.
